# Результаты

Здесь будут итоговые таблицы и графики.

Каждый результат должен сопровождаться:
- источником и периодом данных;
- параметрами расчёта;
- указанием кода или ноутбука, который его создаёт;
- пояснением отличий от исходной статьи.

Графики и таблицы не считаются воспроизведением статьи,
пока сопоставимость данных не подтверждена.
