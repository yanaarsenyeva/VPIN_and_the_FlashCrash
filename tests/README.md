# Проверки корректности

Планируемые проверки:

- сохранение общего объёма при формировании бакетов;
- правильное разделение записи между соседними бакетами;
- корректность tick rule при неизменной цене;
- значения OI и VPIN в диапазоне от 0 до 1;
- обработка неполного последнего бакета;
- воспроизводимость результата.

Проверки будут использовать реальные наблюдения и
арифметические проверки результатов.
