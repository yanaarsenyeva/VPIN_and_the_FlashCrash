# Данные проекта

## Локальные папки

- raw/ — исходные файлы поставщика, без изменений.
- processed/ — подготовленные данные для анализа.

Сами рыночные файлы не загружаются в GitHub.

## Статус источника

Подтверждённый источник для воспроизведения статьи пока не выбран.

Кандидатный файл:
- обозначение в источнике: SP;
- источник: Kaggle / Finnhub;
- соответствие инструменту ES: не подтверждено;
- смысл нулевых объёмов: не установлен;
- полнота данных: не подтверждена.

## Правило обработки

Исходные файлы не перезаписываем.
Все преобразования выполняем отдельным кодом.
